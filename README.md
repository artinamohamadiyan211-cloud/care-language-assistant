
# Care Language Assistant

An accessible web application developed as part of a university group hackathon project.

## Project Overview

Care Language Assistant is a browser-based tool designed to encourage more respectful, inclusive and person-centred language in care documentation.

It analyses written care notes and identifies terminology that could be replaced with more appropriate alternatives, helping users improve the language they use when documenting care.

## Key Features

- Automatic identification of specific outdated or less person-centred terms.
- Context-aware terminology replacement suggestions.
- Accept or ignore individual suggestions.
- Original and reviewed note comparison.
- Undo functionality.
- Copy and download reviewed notes.
- Accessibility customisation.

## Accessibility Features

- Multiple colour themes, including dark mode.
- Adjustable text sizes.
- Dyslexia-friendly font options.
- Adjustable text and line spacing.
- Reduced motion settings.
- Keyboard accessibility support.

## Technologies

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Enter a care note.
4. Select "Check note".
5. Review and accept or ignore suggestions.

No additional installation is required.
